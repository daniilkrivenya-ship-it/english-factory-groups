# Фабрика Английского — разговорный клуб Hygge

Короткий лендинг записи на бесплатный онлайн-клуб на английском языке.

- 28 ноября 2026, 13:00 МСК — Даниил.
- 29 ноября 2026, 13:00 МСК — Елена.
- Обе встречи онлайн, 60 минут.
- Форма: дата, имя, удобный контакт, согласие на обработку данных.
- Карточка встречи выбирает дату в форме. Тест уровня и программы групп убраны.

## Отправка заявки

Существующий CRM-first механизм сохранён: main.js подготавливает поля и запускает отправку, mirror.js сначала ждёт подтверждения `ok: true` от `https://englishfactory.ru/api/lead.php`, затем запускает прежний Google backup. Положительный результат формы показывается только после подтверждения CRM. Повторный submit во время отправки заблокирован. При ошибке данные остаются в форме.

`source=group`, `form_name=application` сохранены для совместимости CRM. Поле `goal` содержит «Разговорный клуб · Hygge», выбранную дату, 13:00 МСК и ведущего, чтобы эти данные были видны в существующем поле цели. `format`, `comment` и `original_payload` также содержат сведения клуба; отдельно передаются `club_date`, `club_time`, `club_host`. Указываются и привычные `phone`, `email`, `contact_method`, согласие и UTM-метки.

Фирменные шрифты, шестерёнки, юридический подвал, cookie-уведомление и аналитика сохранены. Дополнительные стили лежат в `assets/css/club.css`.

## Публикация и проверка

GitHub Pages, ветка main, домен из CNAME: `group.englishfactory.ru`.

Браузерная проверка выполнена на десктопе и при ширине 375 px. Обе даты и сформированные payload проверены с локальной заглушкой CRM и резервной отправки, без создания реальных лидов. Реальная доставка до CRM и Google при этой проверке не выполнялась.
