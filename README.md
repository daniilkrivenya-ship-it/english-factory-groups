# Фабрика Английского — запись в группы

Специальная короткая версия основного сайта для одного действия: записи в групповое обучение.

## Структура страницы
1. Шапка:
   - Основной сайт
   - Тест
   - Записаться
2. Три направления — перенесены с основного сайта.
3. Форма заявки — перенесена с основного сайта.
4. Служебный футер и cookie-уведомление.

## Что изменено относительно school.englishfactory.ru
- Удалены все остальные секции сайта.
- В карточках направлений удалены плашки форматов.
- В раскрытых карточках удалены индивидуальный формат и сопровождение.
- Остаётся только стоимость группового обучения.
- В форме удалён видимый выбор формата.
- `format=В группе` передаётся скрыто.
- `source=group.englishfactory.ru`.
- В поле направления оставлены только три направления этой страницы и вариант «Пока не знаю».
- Никаких дат старта и расписания на странице нет.

## Домен
`CNAME` уже содержит:

group.englishfactory.ru

Для GitHub Pages потребуется CNAME-запись DNS `group` на GitHub Pages вашего аккаунта/репозитория.
